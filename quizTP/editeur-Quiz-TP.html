💡 Comment utiliser votre quiz ?

  • Double-clic : Ouvrez le fichier directement sur votre ordinateur dans n'importe quel navigateur.
  • Intégration Web (Iframe) : Vous pouvez téléverser ce fichier unique sur votre site ou CMS et l'afficher via une balise <iframe src="mon-quiz.html"></iframe>.
  • Hébergement facile : Déposez-le gratuitement sur des plateformes comme GitHub Pages, Netlify ou Vercel pour le rendre accessible en ligne.
